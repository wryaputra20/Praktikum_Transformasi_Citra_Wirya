## Deskripsi
Praktikum ini membahas implementasi transformasi citra digital menggunakan Python dan OpenCV.

## Jenis Transformasi
1. Translation
2. Scaling 0.5 dan 2
3. Rotation 45°, 90°, dan 180°
4. Horizontal Flip
5. Vertical Flip

## Tools yang Digunakan
- Python
- Google Colab
- OpenCV
- NumPy
- Matplotlib

## Hasil Praktikum
Hasil praktikum berupa citra asli dan sembilan tampilan hasil transformasi citra digital.

## Kesimpulan
Transformasi citra digital dapat digunakan untuk mengubah posisi, ukuran, dan orientasi gambar menggunakan Python dan OpenCV.
